
Readin is  Microblogging  web-application  based on spring boot in the backend and React  in the Front-end 
# Ics Wtp Readin



## features Implemented 
in this app, one can 
* create, edit and delete his own posts
* follow other users and see there posts 
* Un-liking posts currently liked by the user
